# Every host the app contacts

Generated by `scripts/hosts-doc.py` from `Casberi/Casberi/Model/NetworkReach.swift`. Do not edit by hand.

Casberi has no server. Every request goes from the device straight to the service it names, and this is the whole list: 119 services, 249 named hosts. `scripts/network-reach-audit.sh` fails the build on a host in the source that is not declared here, and the app records the hosts it actually reached so the two can be compared (in the app: What this app reaches).

Two kinds of host cannot be listed by name: one that comes from your own input (a feed you follow, your own node), and one a vendored SDK builds at runtime. Those rows say so in words.

"Through Tor" applies on iPhone and iPad. The Mac build has no Tor and reads directly.
