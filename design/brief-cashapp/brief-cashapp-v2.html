What changed, and why

Your note kills more than copy. A brief that can't say "14 landed" loses both of its volume modules — and the synthesis notes lose a whole shape, because "most of it landed before 10am" is a tally wearing a sentence.

Cut

sourceMix"What landed" — gone. Its entire content is Bluesky 6, Photos 4, RSS 3. A composition of volume, when volume isn't news. The Themes map takes its slot and its geometry.
hourStrip"When it landed" — gone. Eight buckets of arrival counts. The only case it earned was the overnight window, and the away-gap sentence already covers that in words.
Counting notesA synthesis note whose payload is a number ("most of it landed before 10am", "4 of 6 links") stops qualifying. A note must name a thing, a shift, or an attribution — the existing module doctrine (§166), now enforced on notes too.
The N things linethemesDocument still passes counts for area — but the cell stops printing them. Size already says which theme is bigger; the number is the same fact twice, and it's the fact nobody wanted.

Kept, and re-ranked

MoneyThe crown, unconditionally, when a wallet is watched. This is the one place a count is still the event (money moving), and the one number that changes while you sleep. It keeps its curve; the treemap of holdings stays in the wallet room — one map per screen, and this screen's map is themes.
The sentenceB's voice survives as the line under the number: "Up $184 today. ETH did the lifting." Attribution, not restatement — it says which holding moved, which the number alone can't.
ThemesSecond, at full size, straight on the page. Same TagMap the All feed draws, same §145 wash (one hue, opacity by share) and no icons — a tag spans sources by nature. A cell tap re-runs the retriever, as it does in the feed.
The map's sentenceThe one line the map can't draw: what's new. "Foldables is new this week" is the observation the old dominantTopic note was reaching for — a shift, not a share.
Leads · watchlist · nextUnchanged in content, de-carded in form: gray label, rows beneath, one chevron grammar, mention still shown in full because the post's words are the lead.

The no-wallet case

Without a watched wallet the crown falls through to Themes, drawn at hero size with its sentence promoted to the display line — the same screen minus a section, not a different design. This is the honest version of the ruling: money leads because it's yours and it moved, not because it's the app's favorite subject.

Two things to watch

Themes needs a shift, not a snapshot. Six tags that barely move day to day make the map look identical every morning — the All feed already solved this with a seen-digest that collapses an unchanged map to one line. The brief should inherit that: if today's clusters equal yesterday's, the map shrinks and its sentence carries the screen.

A count still hides in "Up next". "2 more overdue" is volume — but overdue is a state, not an arrival, so it stays. The rule isn't "no numbers"; it's no numbers about how much arrived.

Render depth. Fewer surfaces helps, but the crown, the map and every row here still mount through GenRender's generic Widget/Row path — the one that has tipped the main-thread stack three times. Any new renderer for these draws flat, a plain HStack of Text, exactly like WalletRow.
