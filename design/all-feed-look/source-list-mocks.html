Smallest change: the row code is untouched; only the per-row background+shadow becomes per-day. Long days become tall slabs — the header count keeps them honest.

B · Row parcels — the tokens' idiom, everywhere

The other way to end the two-system clash: promote the token rows' existing treatment to every row. Each row its own quiet parcel, uniform gap, no shared card to seam. Days become runs of parcels under their header — the settings screen already reads this way (§161).

More surfaces on screen; day boundaries lean harder on the headers. Flat fills, shadow-free — depth comes from the gap, not a ridge.

C · Open ledger — rhythm instead of surfaces

No fills at all: rows sit on the ink, day headers step up to 20pt-800 and carry the whole structure, the figure column holds the right edge. No seams because there is nothing to seam. The visualizations above stay parcels — content cards, list air.

The frame-A question answered concretely: card-less without hairlines. If §160's "parcels beat strata" extends to LISTS, this loses; if parcels were about the READS (map, chart, mosaic) and lists are a different animal, this is the calmest screen of the three.
