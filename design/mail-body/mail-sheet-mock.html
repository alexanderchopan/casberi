After — the real body, and a direct hand-off

The IMAP fetch adds BODY.PEEK[TEXT] (read-only — the peek never flips the server's read flag), decoded to plain text and trimmed of quoted reply chains/signatures. MailContentView already renders this for free — it just needed real body text in content. Open in Mail is new: built from the message's Message-ID header (already present in ENVELOPE, just unparsed today) as a message: URL — the same scheme Mail.app itself resolves to jump straight to that message, not the inbox.

Unverified until a real device check: the message: deep link is a long-standing Mail.app convention, not a documented public API — needs confirming it opens the exact message on-device before this ships as more than a best-effort verb.
