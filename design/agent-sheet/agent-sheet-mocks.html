2What's actually wrong — four findings, each invisible to every check we run

A build succeeds, the screen sweep passes, and the sheet renders perfectly in all four cases. That is the whole reason this needs a mockup and then a harness rather than a patch.

1 · The transcript is stored and drawn by nothing

ChatBubbles(text: thing.content) — and content is the opening ask. The conversation lives on enrichedText, which is retrieval-only by the 2026-07-15 ruling.

This is verbatim the Obsidian defect fixed on 2026-08-09: “the vault bridge read a person's notes, indexed them for search, and showed nobody the note — you could ask about it but never open it and actually read it back.” Same sentence, four seats over.

ThingContent.swift:318 · ChatGPTImport.swift:104

2 · ChatBubbles draws no bubbles

It splits on \n and puts every line in the same faint slab, same alignment, same weight. The transcript's format is "You: …" / "ChatGPT: …" — the speaker is inside the string.

So even handed the real transcript, today's view renders a column of identical grey blocks with the role as literal typing. A conversation's one structural fact — who is talking — would render as punctuation.

ThingContent.swift:770

3 · A 61-turn session reads like a 3-turn one

messageCount is stamped by every one of the four importers and is drawn on exactly one screen in the app — a social thread's “rest”. Never on a chat sheet.

It is also the only honest way to know the stored transcript was cut: turns counted before the clamp, against turns present in the stored text. No new field needed to say so.

ChatGPTImport.swift:275 · SocialPostViews.swift:58

4 · 1Claw's expiry is stored and never shown

Grants land kind: .link with dueAt = expires_at. The sheet's Due row requires kind == .reminder. So a grant expiring in six days looks identical to one that never expires — on the surface whose entire job is “what can this agent reach”.

And its link card previews the same dashboard URL for every grant in the corpus. A card that is identical on every row is not information, which is the inverse of last night's ruling about a URL you can't tap.

OneClawBridge.swift:140 · ThingSheetView.swift:955

4The rulings this rests on

  1. The gate is a data test, never a source list (§363, inherited). “Does this record carry a transcript?”, not “is this ChatGPT, Claude or Gemini?”. The seat that ships next week is covered the day it lands, and a chat import that predates enrichedText falls through to exactly today's behaviour rather than regressing.
  2. The transcript earns the Obsidian exception, and for the same stated reason. enrichedText stays retrieval-only in general; here it isn't a payoff fact carved out of a discarded read, it is the conversation itself, clamped further out than the row excerpt. That is the second instance of a precedent already written down, not a new rule.
  3. The role is parsed off the stored prefix, and a line that doesn't carry one is drawn as prose. Speakers are written into the string at import ("You: …"), so a turn is recovered, never inferred. An unparseable transcript renders exactly as it does today — one column of slabs — instead of mis-attributing somebody's words.
  4. “Cut” is derived from two numbers we already store, never from a new field: messageCount counts turns before the clamp, and the stored text carries what survived it. So the sheet can say “stored to here” truthfully, and stays silent when nothing was cut. No new Thing property anywhere in this pass, and therefore no CloudKit Production deploy.
  5. Gemini says what its export doesn't have. One turn and no reply is a whole, correct reading of Takeout — so the sheet names that, rather than drawing an empty assistant bubble that reads as a failed load.
  6. A grant's clock is drawn only when a clock exists. dueAt present → status word, runway, expiry row. Absent → none of the three, and a sentence saying it stands until revoked.

What this deliberately does not build

  • No fourth shape for Claude Code. A session is a conversation with a project stamped. Giving it its own anatomy would mean two views drawing one fact, which is how a screen starts contradicting itself.
  • No turn-level timestamps. Only the session's start is stored; a per-turn clock would have to be invented, and an invented time on a receipt is believed.
  • No “model” row. None of the four importers stamps which model answered — ChatGPT's export carries it inconsistently and Takeout not at all — so there is nothing true to put there.
  • No agent name on a 1Claw grant. The policy record carries vault, path, permissions and dates; which agent holds the key is resolved at auth and is not on the row. Naming one would be a guess on the screen where a guess is most expensive.
  • Nothing writes. Revoke opens 1Claw, the way an approval opens Revoke.cash.

Shipped, and what guards it

AgentSheet.swift is Foundation-only — the shape decision, the turn parser, the clamp derivation and the grant's clock — so scripts/agent-sheet-selftest.sh compiles it whole and unmodified: 67 assertions, 17 mutations, 19 drift guards, wired into verify.sh. Every failure here is a silent wrong answer that renders perfectly, so the harness is the only thing that can see one.

Its sharpest guard is not an assertion. The speaker labels are a wire format four OTHER files write, so the harness reads ChatGPTImport, ClaudeImport, ClaudeCodeSession and GeminiImport and fails the build if any of them stops writing the labels this parser reads. That break is invisible from inside AgentSheet and silently returns every chat sheet in the app to the one-line rendering this pass exists to end.

Two things changed between the first draft of this page and the code. The hero is the conversation's own NAME, not the ask — the draft had the ask as the headline and as the opening turn, printing it twice; the ask takes the hero slot only where the title is provably a clamp of it. And the Claude Code panel's tool bubble is gone: the transcript folds tool traffic into the assistant's turns, so drawing one would have been invented structure.

Demo parity. The demo's chat rows carried one summarising sentence in enrichedText, which parses to zero turns — so the demo would have shown an empty conversation on the very pass built to draw one, indistinguishable from a broken parser. The seeds now carry real transcripts in the importers' own format, and the 1Claw rows carry the bridge's real 1claw:policy: ref shape instead of demo:1claw:, which nothing keyed off grants could ever have matched.
