Wallet — today vs merged

Today Home stacks the box, eight tiles, the account menu, an Actions block, and an Overview that repeats seven of the tiles as rows. Merged: the Overview goes (red), the Accounts tile goes (the menu already picks an account), and Follow address becomes the last tile (green), as Watch is on GitHub — so Home ends in the newest activity, like every other room.

What's lost: the Overview's reading before the tap ("4 live approvals", "Nothing on leverage", §747). Each scope still says it in its own box once tapped, and a tile's attention dot still flags the one that needs you. Word to rule on: the tile says "Follow" (the row said "Follow address"; a tile word is one word).
