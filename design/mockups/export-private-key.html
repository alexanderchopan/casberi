Export a private key: the way out without Casberi

The account is a Safe. Its keys are its owners, so we never export an existing key (this iPhone's can't leave the Secure Enclave, and the recovery key is one only Casberi can read). Export creates a new key, adds it as an owner, and shows it once. It's a plain Ethereum private key (64 hex characters), not a phrase, so MetaMask, Rabby or Rainbow import it as "Import private key". That wallet then opens the account in Safe's app.

With a spend limit on, the key can't act alone

What this settles and what it doesn't.

• A private key, not a phrase (your call). Every major wallet imports one, and it's the same key a phrase would derive, without the 12 words.

• Only Safe's contracts (§1380): it's one more owner via addOwnerWithThreshold, which the account already does for the Signer.

• Robinhood: left off until we confirm Safe's app opens accounts there. Otherwise the key would be an owner of something no other wallet can reach.

• Corrects §1421 item 2. The recovery key is a raw Keychain key, not a passkey Safe's app can find, so it was never the way out.

• Fee: it needs a little ETH on each network, like setting up the recovery key. With none, the row says "with your first send" (§1457 item 4).
