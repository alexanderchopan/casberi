Counts as buttons: Sources and Apps

Each screen is shown as it is today, then with the counts in the box as the filter. The box keeps its size and position on every screen (§1136f); pressing a count changes only the list below it. Demo data. The glyphs stand in for the real SF Symbols.

What this asks of the rulings
  • §1136 item 4 ("not buttons") and §1136h (six kinds on the bar) are amended for Sources. Its reason, that a count which pressed would be a second way to the same filter, no longer holds once the six leave the bar.
  • Apps is a sheet since §1136, so it's the one sheet with a box. Its box sits higher than on the You places because a sheet has no You tiles. The alternative is to make Apps a place again.
  • Search returns to Sources, on the bar this time. That reverses §1136f's "we have to remove search".
  • Five across is tight on the smallest phones. At 320pt the longest label ("Testnets") still fits at 12pt, but only just. If a category is ever added, the grid goes to 4-4-3 and the box keeps its height.
