# Contributing

Casberi is built by one developer and does not take outside contributions. Pull requests will be closed without review.

The source is public so that it can be read, audited and built.

- **Found a security problem?** Report it privately. See [`SECURITY.md`](SECURITY.md).
- **Found a bug?** Open an issue with what you did, what happened, and the version (Settings shows it).
- **Want to change it?** The licence is GPLv3: fork it. A fork must use its own name, icon and logo (see the README).
