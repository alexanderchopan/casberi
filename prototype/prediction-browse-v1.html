Prediction markets — showing what's available

Three columns: today, then the same data rearranged into a browse room, then both venues merged. Odds and questions below are illustrative, not a live read — the point is the arrangement.

Everything the two proposed columns show is already fetched today: Kalshi's category is parsed on every open event and used only as a search haystack; previousProbability is parsed into Resolved and never rendered in a row; closeTime and the event grouping arrive with each hit and are dropped. Nothing here needs a new endpoint. Per the existing ruling, volume is never a number — Kalshi contracts and Polymarket dollars aren't comparable — so a light book reads as "Thin book", never as a figure.
